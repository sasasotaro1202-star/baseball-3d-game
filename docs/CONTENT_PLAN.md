# Content and Systems Plan

## Player database
Target: roughly 2,000 historically notable players, represented with independently authored metadata and ratings. Names/identity data must be sourced lawfully; do not fabricate biographies or copy proprietary game databases.

## Game modes
Home, Exhibition, Season, Training, Roster, Collection, Gacha, Settings, Replay. Build each as an independent mode so new systems do not destabilize match simulation.

## Gacha
Implement original rarity, banner, pity, duplicate conversion, currency and animation systems. Do not copy another game's exact probabilities, UI, text, or presentation.

## Presentation
Original baseball broadcast-style presentation: title screen, home hub, scoreboard, inning state, pitch/bat feedback, results, reward reveal, collection pages, menus, transitions, camera language and haptics. The target is polished commercial-game quality, not an exact clone.

## Development order
1. deterministic simulation core
2. home/mode shell
3. pitching/batting timing
4. ball physics and outcomes
5. fielding/baserunning AI
6. roster/team/season systems
7. collection + gacha economy
8. replay/camera/presentation
9. content expansion toward 2,000 players
10. performance, accessibility, persistence, iPhone QA
